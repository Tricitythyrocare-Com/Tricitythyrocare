# Tricity Thyrocare Collection Centre — Booking Website

This version provides a professional diagnostic-test booking flow with a mobile-friendly cart and appointment form.

Brand/name used throughout the website: Tricity Thyrocare Collection Centre.

Included booking features:
- Number of persons
- Price breakdown and total payable
- Pincode check field
- Beneficiary details
- Communication and collection address
- Collection date and time slot
- Optional hard-copy reports
- Appointment booking through WhatsApp
